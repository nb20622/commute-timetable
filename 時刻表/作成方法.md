# 平日時刻表CSVの作成方法

2026-10-12に、公式の現行ダイヤから4区間を再作成した。
作成処理は `scripts/create_timetables.py`、取得元URL・照合結果・元資料のSHA-256は `時刻表/作成記録.json` に残してある。

## 元資料と到着時刻の確認

- 京阪：[全列車時刻表](https://www.keihan.co.jp/traffic/time-fare/time.html)の「平日 淀屋橋・中之島方面行き」。今回のPDFは2026年8月24日変更。
  PDFの同じ列車の列を使い、西三荘の発車、守口市の**発車**、関目の時刻を対応させる。
  関目を通過する列車、関目まで行かない列車は含めない。西三荘→守口市の乗換は含めない。
  **関目はPDF上では発車時刻**なので、到着として使う前に別の区間時刻表で分単位の一致を確認する。
  今回は京阪公式トップページの乗換検索が案内するNAVITIMEの
  [門真市→関目の区間時刻表](https://www.navitime.co.jp/diagram/depArrTimeList?arrival=00001360&departure=00008698&line=00000285&updown=1)を参照し、
  門真市発・関目着の105便が公式PDFの同じ列車の分単位の時刻と全便一致した。
  照合用CSVは `時刻表/照合/keihan_kadomashi_to_sekime_2026-08-24.csv`。
  次のダイヤ改正時は照合用CSVも作り直す。プログラムは不一致があれば出力せず停止する。
- 地下鉄：公式の[関目成育・今里方面](https://kensaku.osakametro.co.jp/timetable/ja/subway/dia/station/29583/1027/1/)と
  [今里・南巽方面](https://kensaku.osakametro.co.jp/timetable/ja/subway/dia/station/25840/1023/1/)の平日発車時刻を取得。
  [公式経路検索](https://kensaku.osakametro.co.jp/route/)で、それぞれ関目成育→今里、今里→新深江の各便の到着時刻を取得する。
  今回は2025年10月14日現在のダイヤ。祝日を避け、2026-10-13（火）を指定した。
  24時台は翌日の0時台で検索し、CSVには24:xxとして保存する。

関目成育→今里は9分または10分、今里→新深江は1分または2分だった。
一律に所要時間を足したり、到着駅の発車時刻から一律に1分引いたりしない。

## 作成コマンド

Python 3、curl、PyMuPDFが必要。通常のPython環境なら次で依存を入れる。

```sh
python3 -m pip install -r scripts/requirements-timetable.txt
```

以下は今回と同じダイヤを作る例。次回は検索日を**祝日でない平日**に変更し、
キャッシュフォルダを新しくする。京阪の改正があれば照合用CSVも新しいものを指定する。

```sh
mkdir -p /tmp/timetable-2026-10-12
curl -L --fail https://www.keihan.co.jp/traffic/time-fare/pdf/time01-2.pdf -o /tmp/timetable-2026-10-12/keihan.pdf
python3 scripts/create_timetables.py \
  --service-date 2026-10-13 \
  --keihan-pdf /tmp/timetable-2026-10-12/keihan.pdf \
  --keihan-arrival-check 時刻表/照合/keihan_kadomashi_to_sekime_2026-08-24.csv \
  --cache-dir /tmp/timetable-2026-10-12 \
  --output-dir /tmp/timetable-2026-10-12/generated
```

地下鉄の検索結果が駅の発車時刻表と一致しない場合や、乗換のある結果が返った場合も停止する。
取得済みのキャッシュで再実行する場合は `--offline` を追加できる。
作成成功後、4本のCSVを `時刻表/` と `commute-timetable/data/` にコピーし、作成記録も `時刻表/` に保存する。
アプリのバージョン更新・テスト・公開手順は [README](../README.md#ダイヤとバージョンの更新) を参照。

今回の結果：西三荘→関目105便、守口市→関目105便、関目成育→今里145便、今里→新深江167便。
今里→新深江は旧CSVと一致。関目成育→今里は到着時刻36件を修正した。
